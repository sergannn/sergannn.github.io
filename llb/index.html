Лига бильярдистов

Приложение для турниров, игроков и рейтингов по бильярдным дисциплинам.

О приложении

Лига бильярдистов помогает быстро находить турниры, игроков, карточки участников и рейтинги без лишней навигации по сайту.

  • Прошедшие и будущие турниры.
  • Поиск игроков.
  • Карточки игроков с городом, аватаром и рейтингами.
  • ЭЛО по дисциплинам.

Поддержка

Конфиденциальность

Приложение показывает турнирную и рейтинговую информацию. Аккаунт для просмотра не требуется.
